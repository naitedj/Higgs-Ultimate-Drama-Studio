## Цель

Форк `timoncool/Higgs-Ultimate` (лицензия Apache-2.0), переименованный в **Drama Studio**.
Добавить второй движок синтеза речи — **Fish Audio Drama 3 через speech.cpp** — рядом с существующим
движком Higgs Audio v3, с переключателем движков в интерфейсе. Интерфейс на русском, как в оригинале.

Пользователь сравнил: Drama 3 звучит лучше Higgs, а интерфейс Higgs Ultimate удобнее, чем страница
`speech serve`. Отсюда задача: интерфейс Higgs Ultimate + движок Drama 3 + удобства для озвучки книги
(рассказчица и персонажи).

## Как устроен Higgs Ultimate

- Tauri 2. Бэкенд на Rust: `desktop/src-tauri/src/`, интерфейс на TypeScript без фреймворка: `desktop/src/`.
- `engine.rs` загружает движок `audiocpp_engine.dll` через `libloading` (динамически, без линковки)
  и вызывает C API из `app/desktop_api/audiocpp_api.h`.
- `lib.rs` — команды Tauri: `load_engine`, `load_model`, `generate_tts`, `generate_voice_clone`,
  `generate_finish_sentence`, `transcribe_audio` (Parakeet), `diarize_transcribe`, `build_speaker_voice`,
  `normalize_wav`, галерея голосов и т. д.
- Клонирование в Higgs уже использует эталон + текст эталона (`ref_text`) с авторасшифровкой Parakeet —
  это совпадает с тем, что нужно Drama 3.
- `desktop/src/main.ts` (~6500 строк) — весь интерфейс; `desktop/src/i18n.ts` — русские строки.
- Сборка: `cd desktop && npm ci && npm run build` (= `tauri build`), Windows. В CI — `windows-2022`.

## Как подключать speech.cpp

- Загружать `speech.dll` **динамически** через `libloading`, как `engine.rs` грузит audiocpp.
  Не линковать `speech.lib`: в CI библиотеки нет, сборка должна проходить без неё.
- Путь к `speech.dll` — настройка в программе (по умолчанию папка пользователя выше, кнопка «Обзор»).
- Путь к модели — по умолчанию искать `Drama-35B-A3B-v3-Q4_K.gguf` в `%LOCALAPPDATA%\speech.cpp\models\`,
  иначе «Обзор».
- Справка по API: в исходниках speech.cpp (`github.com/nyosegawa/speech.cpp`) файлы `include/speech.h`,
  `docs/c-api.md`, `docs/models/drama3.md`. Сверять сигнатуры с `speech.h` версии 0.8.10.
- Нужные функции C API (по `docs/c-api.md`):
  - загрузка модели, запрос, `speech_request_set_text`, `speech_request_set_string/int/float/bool`,
    `speech_synthesize` с колбэком (звук приходит кусками по мере готовности), `speech_request_cancel`;
  - `speech_voice_make_from` + `speech_voice_params_*` (`add_reference`, `set_transcript`, `set_speaker`,
    `add_voice`) — создать файл голоса Drama 3 из записи и её текста;
  - `speech_voice_add` — добавить голос в уже загруженную модель без перезапуска;
  - `speech_model_info_*` — список опций модели, их значения по умолчанию и диапазоны.

## Факты о Drama 3 в speech.cpp

- Опции: `voice` (обязательно: `none` или добавленный голос), `seed`, `max_seconds` (47,6 по умолчанию,
  до 95,1), `top_k` (по умолчанию 30, от 1 до 4097), `top_p` (0,9), `temperature` (1),
  `experts_on_cpu` (true = разрешить считать часть экспертов на CPU; false = отказ, если не влезает в GPU).
- Q4_K занимает около 21,7 ГиБ видеопамяти. На 3090 с открытым браузером может не влезть целиком —
  тогда часть слоёв считается на CPU (медленнее). Показывать пользователю, сколько слоёв на CPU.
- Говорящие в тексте: `<|speaker:0|>` … `<|speaker:15|>`. Текст до первого тега — говорящий 0.
- Ремарки в квадратных скобках: `[laughs]`, `[sigh]`, `[whispers]`, `[short pause]`, свободные описания
  вроде `[tender, very soft]`. Действуют с места, где стоят. Пишутся по-английски.
- С голосом `none` подсказка в начале вроде `[deep, low male voice]` задаёт голос.
- Длинный текст режется на куски ~300 байт UTF-8, каждый кусок помнит первый и предыдущий.
- Голос Drama 3 = файл голоса (запись + точный текст записи). Голый WAV не подходит.

## Известные проблемы и решения (проверено с пользователем)

1. **Длинные паузы-зависания (10+ секунд тишины).** Причина: `top_k = 30` по умолчанию — на паузе модель
   застревает в «кодах тишины». `top_k = 4097` (без ограничения, top_p продолжает работать) убрал
   большинство. **Делать 4097 значением по умолчанию** в нашей программе. Остаточные паузы 2–4 с бывают.
2. **Теги пауз рискованны**: `[short pause]`/`[long pause]` в начале реплики могут дать тишину.
3. **Эталон голоса**: должен заканчиваться на конце предложения; текст должен совпадать с записью
   слово в слово (нехватка последних слов в тексте — частая причина «замолкания»).
   Эталон с длинными паузами тоже вредит.
4. **PowerShell 5.1 теряет заглавные русские буквы (В, Г) при вставке.** Поэтому весь ввод текста —
   только в интерфейсе программы, никакой передачи русского текста через консоль.
5. **MP3 не принимается** `speech voice`. В программе всегда конвертировать эталон в WAV
   (в Higgs Ultimate уже есть декодирование через symphonia и `ensure_wav`).

## План работ

### Этап 0 — сборка без изменений
- Форк `timoncool/Higgs-Ultimate` в аккаунт пользователя (пользователь делает сам на сайте).
- Склонировать форк на диск, положить этот файл `CLAUDE.md` в корень репозитория.
- В `desktop/src-tauri/tauri.conf.json`: `productName` → `"Drama Studio"`,
  `identifier` → `"com.dramastudio.app"`.
- Добавить `.github/workflows/build-windows.yml`: на push в `main` и вручную — `npm ci`, `npm run build`,
  выгрузка `desktop/src-tauri/target/release/bundle/nsis/*.exe` и `msi/*.msi` как артефакт.
- Push → сборка → пользователь ставит и проверяет, что программа открывается.

### Этап 1 — движок Drama 3
- Новый модуль Rust (например `speech_engine.rs`): загрузка `speech.dll`, загрузка модели,
  синтез с опциями и потоковым звуком, отмена, сообщения об ошибках.
- Команды Tauri для этого движка, по образцу существующих.

### Этап 2 — озвучка в интерфейсе
- Переключатель движка Higgs / Drama 3.
- Настройки Drama 3: seed (пусто = случайный, показывать использованный), top_k = 4097 по умолчанию,
  top_p, temperature, max_seconds. Настройки запоминаются.
- Панель кнопок-ремарок с русскими подписями, вставляющих английские теги в позицию курсора:
  вздох `[sigh]`, смех `[laughs]`, шёпот `[whispers]`, нежно `[tender, soft]`, грустно `[sad]` и т. д.

### Этап 3 — голоса
- Загрузка WAV/MP3 → конвертация в WAV → расшифровка Parakeet → редактируемое поле текста →
  кнопка «Создать голос» → `.voice.gguf` в галерее → `speech_voice_add` сразу.
- Подсказка: обрезать эталон по концу предложения, 10–20 с чистой речи.

### Этап 4 — мультиспикер
- Список персонажей: имя → голос (или `none` с описанием голоса).
- Сценарий в виде «Имя: реплика», программа сама превращает в `<|speaker:N|>` и собирает общий
  файл голосов (`set_speaker`).
- Режимы: вся сцена одним запросом (естественнее) или по репликам (легче переделывать).

### Этап 5 — удобства
- Режим по абзацам: у каждого абзаца свой плеер и кнопка «переделать», в конце «склеить в файл».
- Поиск длинных пауз (например, тишина > 2 с ниже −45 дБ) с автопеределкой куска новым seed
  (до N попыток) и, как отдельная опция, сокращение пауз.
- История дублей: текст, голос, seed, настройки; возврат к удачному.
- Проверка распознаванием: распознать результат и подсветить пропущенные слова.

### Принятые решения (не пересматривать без пользователя)

- top_k по умолчанию 4097 (иначе паузы-зависания). «Стабильный голос» — кнопка, не умолчание.
- Голоса галереи общие для всех проектов, в проект не копируются.
- Голос из загруженной модели удалить нельзя (speech.cpp) → пересозданный получает имя `Имя_2`;
  временные голоса `scene-*` и `studio-*` скрыты из списков (`isHiddenVoice`).
- Ударение: «+» перед ударной гласной (`з+амок` = за́мок).
- Обложек в экспорте нет (пользователь отказалась). M4B — кнопка «📚 M4B книги» (`exportBookM4b`, команда `ffmpeg_m4b`, `m4bMetadata`).
- Программа сама ничего не скачивает (ffmpeg — путь пользователя или PATH; ссылка на ffmpeg.org).
- assetProtocol scope в `tauri.conf.json` дополнен `"**"` — предпросмотр видео с любого диска.
- Тестовый вход `window.__dramaStudioTest` есть только при `import.meta.env.DEV`.
- Персонажи сцены общие для Мультиспикера, Главы и Субтитров; голоса и манеры задаются в Мультиспикере.
